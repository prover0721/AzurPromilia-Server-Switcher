# 蓝色星原：旅谣 — 全服资源共享与切换器 (AzurPromilia-Server-Switcher)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Windows%2010%2F11-green.svg)](#)

> **《蓝色星原：旅谣》（Azur Promilia）PC 端全服资源共享与一键切换启动器。**  
> 只要本机有一份完整游戏资源（约 95GB），即可实现 **官服 ↔ B服 零额外空间秒切**，以及 **日服 / 韩服 / 台服 / 国际服** 通过 **NTFS 硬链接** 共享通用大资源！同时支持作为独立软件运行与挂载至 `GameHub`。

## 📥 下载与安装（普通玩家推荐）

1. 前往本仓库右侧 **[Releases 最新发布页面](https://github.com/prover0721/AzurPromilia-Server-Switcher/releases/latest)**；
2. 下载压缩包 **`AzurPromilia-Server-Switcher-v1.0.0.zip`** 并解压到任意英文/中文路径（内含已内置好的**官服 / B服双服源**与原版启动器）；
3. 确保电脑已安装 Python 3.11+ 及 `PySide6`、`PySide6-Fluent-Widgets`（或置于 `GameHub` 同级目录共用 `.venv`）；
4. 双击 **`AzurPromiliaSwitcher.exe`** 即可启动可视化界面。

## 🛠️ 详细使用教程

### 一、 首次定位游戏目录
1. 打开 **`AzurPromiliaSwitcher.exe`**，程序会自动通过 Windows 注册表与常见盘符定位本机已安装的《蓝色星原》；
2. 若未自动识别或需要切换其他目录，点击右上角 **「手动选择目录」**，选中游戏安装根目录（如 `D:\game\AzurPromilia`）或 `AzurPromilia_Game` 目录即可。

### 二、 官服 ↔ B服 零空间秒切
1. 下载 Releases 完整压缩包的用户已自带官/B 双服源（`官:已就绪 / B:已就绪`）；
   *(若你是通过 `git clone` 获取源码，因 `libcef.dll` 超过 GitHub 100MB 限制未包含在 Git 仓库中，可自行用另一区服客户端点击一次「提取当前服源」，或从 Releases 补全 `assets/cn_sources/`)*。
2. 在主界面点击目标卡片（**官服 (蛮啾)** 或 **B服 (哔哩哔哩)**）；
3. 点击 **「切换 / 同步至 XX」**，等待 1~2 秒完成渠道配置与登录组件热切换（**切服前请先关闭游戏**）；
4. 点击 **「启动当前区服」** 即可直接进入游戏（已自动附带 `-start=azurpromilia_launcher` 参数，无需再经过官方启动器）。

### 三、 日服 / 韩服 / 台服 / 国际服 跨区资源共享（省 95GB 硬盘）
1. **同盘符安装壳目录**：在与国服主目录**同一个磁盘分区**（例如都在 `D:\` 盘）下，使用左侧 **「下载渠道与教程」** 页面提供的官方链接下载对应外服启动器并安装基础本体（**无需下载 95GB 完整资源**）；
2. **绑定壳目录**：回到 **「启动与区服管理」** 页，点击对应外服卡片（如 **日服 (JP)**），再点右上角 **「手动选择目录」** 选中该外服目录；
3. **建立硬链接共享池**：点击 **「切换 / 同步至 日服」**，工具会通过 Windows NTFS 硬链接把国服 `StreamingAssets/.res` 与 `AzurPromilia_Data/.res` 中的通用大文件零空间占用地映射到外服目录；
4. **增量补齐语言包**：首次进入外服时，游戏会自动增量下载少量该服独有的语言文字包与差异资源；以后在各服之间来回切换均无需重复下载；
5. **大版本更新前提示**：外服或主目录迎来大版本更新前，建议在右侧点击 **「更新前解除硬链接」**，更新完成后再重新同步。

### 四、 其他实用功能
- **角色反虚化**：点击右侧 **「应用反虚化」** 会自动备份被替换的官方原版文件（并自动解除硬链接避免误改其他服），支持随时点击 **「还原官方原版」** 恢复。
- **常用目录直达**：支持一键打开游戏根目录、游戏截图目录（`Pictures\LSXY_PHOTO`）、游戏日志目录。
- **启动参数与本地账号快照**：支持无边框窗口（`-popupwindow`）、自定义分辨率，以及保存/切换 `HKCU\Software\manjuu\AzurPromilia` 本地账号配置快照。
- **CLI 命令行**：
  - `python main.py --scan`：扫描本机游戏目录与区服状态
  - `python main.py --server official --launch`：切换至官服并直接启动
  - `python main.py --audit`：检查 NTFS 硬链接健康度与节省空间
