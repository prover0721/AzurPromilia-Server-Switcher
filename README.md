# 蓝色星原：旅谣 — 全服资源共享与切换器 (AzurPromilia-Server-Switcher)

> **跨服资源共享 + 多服一键切换 + 本地目录自动定位 + GameHub 双栖插件**  
> 专为《蓝色星原：旅谣》（Azur Promilia）PC 端设计的开源工具，支持 **官服 / B服 / 日服 / 韩服 / 台服 / 国际服** 管理与资源共享。

## ✨ 核心特性

- **四重智能目录定位**：自动扫描 Windows 注册表卸载项、本地运行进程、常见盘符路径，并支持手动选择与多目录档案管理。
- **双模混合切换引擎**：
  - **国服同系（官服 ↔ B服）**：自动备份并热切换渠道配置（`mj_sdk/res/app_config.dat`）与登录组件（`AzurPromilia_Data/Plugins/mj_sdk`），秒切且零额外磁盘占用。
  - **跨地区（国服 ↔ 日服 / 韩服 / 台服 / 国际服）**：各外服保留独立轻量壳目录（主程序、登录组件、独有语言文字包），对 `StreamingAssets/.res` 与 `AzurPromilia_Data/.res` 通用大资源执行 **Windows NTFS 文件级硬链接** 共享，避免重复下载语言包与校验冲突。
- **空间账本与硬链接体检**：直观展示逻辑占用 vs 物理实际占用（节省磁盘空间），支持硬链接完整性校验与大版本更新前安全还原。
- **一键直启与常用目录直达**：绕过启动器直启游戏（支持 `-popupwindow`、自定义分辨率等参数），一键直达游戏根目录、截图目录（`LSXY_PHOTO`）、日志目录。
- **本地配置快照**：支持保存与切换 `HKCU\Software\manjuu\AzurPromilia` 本地设置与账号缓存快照。
- **双栖运行**：既可作为独立桌面软件运行（`main.py` / CLI），也可通过 `plugin/` 目录无缝挂载至 `GameHub`。

## 🚀 快速启动

- **EXE 启动（推荐）**：直接双击项目根目录 `AzurPromiliaSwitcher.exe`（如需重新编译可执行 `build_exe.ps1`）
- **Python 启动**：`python main.py`
- **CLI 命令行**：
  - 检测本机游戏：`python main.py --scan`
  - 切换并启动：`python main.py --server bilibili --launch`
